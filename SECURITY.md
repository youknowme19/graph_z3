# Security Policy for NeuroZ3

## 1. Supported Versions

Security updates are applied to the active `main` branch.

| Version | Supported |
| :--- | :--- |
| `main` (Latest) | Yes |
| Historical Releases | Limited to critical security patches |

---

## 2. Reporting a Vulnerability

If you discover a potential security vulnerability within NeuroZ3, please do not file a public issue. Instead, report it responsibly through private security channels:

- **Email**: Submit vulnerability details to the project maintainers.
- **Content**:
  - Detailed description of the vulnerability.
  - Minimal reproducible example or proof-of-concept binary.
  - Potential impact and affected components.

---

## 3. Vulnerability Handling SLA

- **Initial Response**: Within 48 hours of report receipt.
- **Assessment & Triage**: Confirmation within 5 business days.
- **Remediation & Patch**: Targeted within 14 business days of confirmation.

A public advisory will be published upon release of the remediated version.
