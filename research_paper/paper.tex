\title{NeuroZ3: Risk-Prioritised Neuro-Symbolic Verification and Federated Exploit Synthesis for Stripped Binaries}

\author{\IEEEauthorblockN{\vspace{-2.2em}}}

\begin{abstract}
Coverage-guided fuzzers explore program execution state spaces broadly but blindly, while dynamic symbolic execution (DSE)
engines reason with mathematical precision but suffer from combinatorial path explosion ($O(2^d)$). Conversely, static
heuristics generate false alarm rates frequently exceeding 85\% on stripped binaries without source code. We present
\textbf{NeuroZ3}, an end-to-end neuro-symbolic framework for stripped binary vulnerability prioritization and verified exploit
synthesis. NeuroZ3 lifts target binaries across multiple architectures (ARM64 Mach-O, x86-64 ELF, PE32) to attributed Control
Flow Graphs (CFGs) over Valgrind VEX Intermediate Representation (IR). Basic blocks are evaluated by an inductive Graph Neural
Network (\textbf{VulnGNN}, employing a 3-layer, 128-dimensional bidirectional GraphSAGE architecture with global CFG context
pooling over a 40-dimensional structural, instruction, API, taint-reachability, and guard-density feature schema) to predict
temperature-calibrated exploitability risk probabilities $P(v)$. Across an 819-binary unified held-out test set, VulnGNN achieves
a \textbf{0.9543 ROC-AUC}, \textbf{0.2739 PR-AUC}, and \textbf{83.56\% Top-5} localization hit rate across 5 cross-validation seeds
(with single-seed peak of \textbf{0.9737 ROC-AUC} and \textbf{85.89\% Top-5}), reducing clean-binary false positive rates by
28.67 percentage points compared to tabular baselines (14.50\% vs.\ 43.17\%) and pruning 99.23\% of basic blocks from prioritization queues in 1.48\,ms.
In downstream bounded symbolic execution, learned priority scheduling reorders path exploration and reduces explored states by
4.5\%--5.4\%. However, rigorous paired Restricted Mean Survival Time (RMST) analysis across 69 paired binaries under a 15.0\,s
budget demonstrates that GNN guidance does not achieve a statistically significant runtime speedup over Depth-First Search
($\Delta\text{RMST} = +0.212$\,s, $p = 0.452$) due to priority queue maintenance and inference overhead. Across a 7-tier
verification taxonomy on 90 binaries, NeuroZ3 synthesizes concrete, replay-verified exploits, demonstrating arbitrary shell command
execution on command-injection targets and reproducible crashes on memory corruption primitives, while auditing and eliminating 10
false positive path-feasibility witnesses in patched controls. To resolve data-silo constraints across enterprises, NeuroZ3
integrates privacy-preserving Federated Learning via Flower (FedProx and FedAvg) over 3{,}604 real stripped binaries across 5
non-IID silos, exchanging compact 997.26\,KB parameter updates and recovering over 91.28\% of centralized Top-5 localization.
\end{abstract}

\section{Introduction}

Zero-day software vulnerabilities carry no prior signatures, requiring automated analysis tools to reason about runtime execution
semantics rather than relying on syntactic pattern matching~\cite{berrios2025zeroday}. In stripped commercial off-the-shelf (COTS)
software, kernel modules, and embedded firmware, the absence of source code, symbol tables, and type definitions severely exacerbates
this challenge. Coverage-guided fuzzers such as AFL++ and LibAFL~\cite{fioraldi2022libafl} execute millions of mutated inputs per second
but explore program branch space stochastically, frequently stalling on complex magic-number checks and deep semantic guards. Pure
dynamic symbolic execution (DSE) engines such as angr and SymCC~\cite{poeplau2020symcc} evaluate precise branch satisfiability by
accumulating first-order logic constraints, yet they fundamentally suffer from exponential path explosion ($O(2^d)$ for branch
depth $d$). Hybrid concolic fuzzers like Driller~\cite{stephens2016driller} and QSYM~\cite{yun2018qsym} query SMT solvers reactively
only after evolutionary fuzzing reaches a coverage plateau, leaving path selection completely unguided by vulnerability likelihood.

Recent advances in deep learning demonstrate that Graph Neural Networks (GNNs) can learn structural and semantic representations
over code property graphs that correlate with vulnerability presence~\cite{sun2026gnnse,wang2023deepvulseeker,jia2025graphspd,zhang2026gnn}.
However, existing vulnerability GNNs suffer from three critical limitations when applied to binary security: (i) they operate almost
exclusively on source code or unstripped ASTs rather than stripped machine code; (ii) many prior evaluations rely on small or synthetic
benchmarks without testing against paired pre-patch and post-patch real-world CVE commits~\cite{ding2024primevul}; and (iii) they act as
passive classifiers that output probabilistic risk scores without synthesizing concrete inputs to prove reachability or exploitability~\cite{malkawi2026ai,neurosymbolic2025}.

Furthermore, deploying deep learning models for binary security is severely constrained by intellectual property and data-secrecy
boundaries. Kernel vendors, defense contractors, financial institutions, and embedded OEMs operate proprietary binaries that cannot be
uploaded to centralized cloud servers for training.

To resolve these interconnected challenges, we present \textbf{NeuroZ3}, a dual-stage neuro-symbolic binary verification framework
evaluated at scale on \textbf{5{,}200 real compiled stripped binaries} (670{,}464 basic blocks, zero synthetic graphs). NeuroZ3 combines:
(i) a 40-dimensional VEX IR basic-block representation and a 3-layer bidirectional GraphSAGE network with global CFG context pooling;
(ii) risk-prioritized symbolic path scheduling that focuses SMT solver budget strictly on top-ranked candidate vulnerability regions;
(iii) formal exploit constraint solving via Z3 to synthesize concrete, replay-verified crashing exploit payloads; and
(iv) privacy-preserving collaborative model training via Federated Learning (Flower framework with FedProx and FedAvg) across
distributed, non-IID organizational binary silos.

\textbf{Contributions.}
\begin{enumerate}
  \item \textbf{Dual-Stage Stripped Binary Neuro-Symbolic Pipeline}: An end-to-end architecture coupling 40-dimensional VEX IR feature extraction and bidirectional GraphSAGE + Global CFG Context Pooling (\textbf{VulnGNN}) with bounded Z3 symbolic execution on stripped binaries without source code or debug symbols.
  \item \textbf{Large-Scale Real-World Stripped CVE \& Multi-CWE Corpus (5{,}200 Binaries)}: We construct and evaluate on \textbf{5{,}200 real compiled stripped binaries} (670{,}464 basic blocks, 907{,}378 CFG edges across 52 CWEs and \texttt{-O0}/\texttt{-O1}/\texttt{-O2}/\texttt{-Os}), combining \textbf{2{,}480 real-world open-source CVE stripped binaries} from 76 C repositories and 292 CVEs (PrimeVul~\cite{ding2024primevul} pre-patch vulnerable vs.\ post-patch fixed twins), \textbf{2{,}681 Multi-CWE NIST Juliet v1.3 stripped binaries}, and \textbf{39 production system utilities}, with zero synthetic graphs and strict DWARF-pre-strip ground-truth labeling.
  \item \textbf{Inductive Risk Prioritization \& Baseline Comparison}: A calibrated risk-depth model achieving \textbf{0.9543 ROC-AUC} and \textbf{83.56\% Top-5} localization hit rate across 5 cross-validation seeds on the 819-binary held-out test set (\textbf{0.9737 ROC-AUC} and \textbf{85.89\% Top-5} single-seed peak). While tabular baselines like XGBoost achieve competitive Top-1 hit rates (52.85\% vs.\ 49.81\%), VulnGNN delivers significantly superior Top-5 recall (+4.68\,pp) and dramatically reduces clean-binary false positive rates by 28.67 percentage points (14.50\% vs.\ 43.17\% for XGBoost).
  \item \textbf{Empirical Analysis of Neuro-Symbolic Guidance Limits}: A rigorous evaluation using Restricted Mean Survival Time (RMST) over 10{,}000 bootstrap resamples and a 4-way scheduler ablation ($N=22$), showing that while GNN heuristics reduce explored states by 4.5\%--5.4\%, priority queue and inference latency offset these gains, resulting in runtime parity with unguided Depth-First Search ($\Delta\text{RMST} = +0.212$\,s, $p = 0.452$).
  \item \textbf{7-Tier Verification Taxonomy \& Concrete Exploit Synthesis}: Formal memory safety negation predicates evaluated in Z3, validated through a 7-tier verification taxonomy distinguishing path satisfiability from native exploitability. We demonstrate live arbitrary command execution on command injection binaries and 4 reproducible memory crashes, while confirming that all 10 SAT witnesses in patched Juliet controls are symbolic execution false positives.
  \item \textbf{Non-IID Federated Learning over Real Binary Silos}: A 5-client Non-IID Flower evaluation over 3{,}604 real training binaries partitioned into disjoint CWE and repository silos, recovering up to \textbf{78.40\% Top-5} (\textbf{88.15\% Top-10}) localization with FedProx while exchanging only 997.26\,KB parameter tensors per round.
\end{enumerate}

\section{Related Work}

\textbf{GNN-based Vulnerability Detection.} GNNSE~\cite{sun2026gnnse} screens smart contracts using GNNs prior to symbolic
execution; however, it targets high-level source code and outputs static labels rather than concrete binary exploit inputs.
DeepVulSeeker~\cite{wang2023deepvulseeker}, Jia et~al.~\cite{jia2025graphspd}, Zhang and Li~\cite{zhang2026gnn}, and
MSGVUL~\cite{msgvul2024} represent source- or patch-level graph classifiers devoid of path execution. Ding et~al.~\cite{ding2024primevul}
demonstrated with PrimeVul that source-level classifiers suffer sharp performance drops when evaluated on paired pre-patch and
post-patch real-world CVE commits under chronological or group splits. NeuroZ3 addresses this directly on stripped compiled binaries
by fusing bidirectional message passing with global CFG context pooling and downstream Z3 SMT path verification.

\textbf{Concolic and Hybrid Fuzzing.} AFL++, LibAFL~\cite{fioraldi2022libafl}, and VUzzer~\cite{rawat2017vuzzer} rely on evolutionary
coverage heuristics without formal path reasoning. Driller~\cite{stephens2016driller} and QSYM~\cite{yun2018qsym} interleave fuzzing
with concolic execution, invoking SMT solvers strictly on coverage plateaus without predictive risk guidance. Scherb
et~al.~\cite{scherb2024divide} decompose CFGs structurally; NEUEX~\cite{xu2020neuex} learns per-fragment neural constraints reactively
when KLEE stalls. In contrast, NeuroZ3 guides path exploration proactively using inductive graph representations and enables
cross-tenant federated training. Table~\ref{tab:comparison} summarizes capability coverage.

\section{System Architecture}
\label{sec:arch}

NeuroZ3 comprises four integrated pipeline stages (Fig.~\ref{fig:arch}): (1) Binary Ingestion and Attributed CFG Lifting;
(2) 40-Dimensional Feature Extraction and Bidirectional VulnGNN Risk Scoring; (3) Neuro-Guided Priority Exploration; and
(4) SMT Exploit Verification and Synthesis. Cross-organization collaboration is enabled via Stage (5): Federated Flower
Aggregation (Fig.~\ref{fig:fl_arch}).

\subsection{Binary Ingestion and Attributed CFG Recovery}
Target binaries across ARM64 Mach-O, x86-64 ELF, and PE32 formats are ingested in stripped form without source code or DWARF
debug symbols. The binary loader audits compiler security mitigations (PIE/ASLR, NX/DEP, Stack Canaries, and RELRO) and resolves
external dynamic library stubs across ELF PLT sections and stripped Mach-O \texttt{\_\_stubs} indirect symbol tables. NeuroZ3 lifts
raw machine opcodes into architecture-neutral Valgrind VEX Intermediate Representation (IR) statements using angr's \texttt{CFGFast},
supplemented by indirect jump resolution~\cite{bailey2025survey}. The recovered binary is represented as an attributed directed Control
Flow Graph $\mathcal{G} = (\mathcal{V}, \mathcal{E}, \mathbf{X})$, where $\mathcal{V}$ denotes basic blocks, $\mathcal{E}$ denotes
directed control transfers, and $\mathbf{X} \in \mathbb{R}^{|\mathcal{V}| \times 40}$ encapsulates basic-block feature vectors.

\subsection{40-Dimensional Basic Block Feature Representation}
To capture fine-grained vulnerability indicators on stripped binaries without relying on internal function names or debug symbols,
each basic block $v \in \mathcal{V}$ is characterized by a normalized 40-dimensional static feature vector partitioned into five
8-dimensional semantic and structural groups:
\begin{equation}
  \mathbf{x}_v = \big[\, \mathbf{x}_{\text{struct}} \,\|\, \mathbf{x}_{\text{inst}} \,\|\, \mathbf{x}_{\text{api}} \,\|\,
  \mathbf{x}_{\text{flow}} \,\|\, \mathbf{x}_{\text{sym}} \,\big]^\top \in \mathbb{R}^{40}.
  \label{eq:features}
\end{equation}
\begin{itemize}
  \item \textbf{Structural \& Topological ($\mathbf{x}_{\text{struct}} \in \mathbb{R}^8$)}: Normalized in-degree $\deg_{\text{in}}$, out-degree $\deg_{\text{out}}$, entry/exit block indicators, strongly connected component loop-header flag, dominator depth, shortest-path distance from entry, and local flow centrality.
  \item \textbf{Instruction \& VEX Statement Density ($\mathbf{x}_{\text{inst}} \in \mathbb{R}^8$)}: Normalized instruction count, block byte size, VEX IR statement count, temporary variable density, arithmetic and bitwise opcode ratios, conditional branch exit flag, and constant literal density.
  \item \textbf{Semantic Call \& Import Categories ($\mathbf{x}_{\text{api}} \in \mathbb{R}^8$)}: External call indicator and imported libc/kernel API family flags resolved via PLT/\texttt{\_\_stubs} (strictly scrubbed of any benchmark tokens): unsafe string/copy routines (\texttt{strcpy}, \texttt{memcpy}, \texttt{sprintf}, \texttt{copy\_from\_user}), format-string sinks, heap/kernel allocators (\texttt{malloc}, \texttt{calloc}, \texttt{realloc}, \texttt{kmalloc}, \texttt{kzalloc}, \texttt{av\_malloc}), deallocators (\texttt{free}, \texttt{kfree}, \texttt{av\_free}), external taint sources (\texttt{fgets}, \texttt{recv}, \texttt{read}, \texttt{fscanf}, \texttt{ssl\_read}), command execution sinks, and bounded safe APIs.
  \item \textbf{Memory Access \& Taint Reachability ($\mathbf{x}_{\text{flow}} \in \mathbb{R}^8$)}: VEX \texttt{Ist\_Store} and \texttt{Iex\_Load} counts, computed (non-constant) pointer dereference ratio, stack-pointer offset access flag, multi-hop CFG reachability from external input sources, multi-hop proximity to deallocation sites, pointer-arithmetic density, and global data reference count.
  \item \textbf{Symbolic \& Bounds-Check Guard Density ($\mathbf{x}_{\text{sym}} \in \mathbb{R}^8$)}: VEX comparison opcodes (\texttt{CmpEQ}, \texttt{CmpLT}, \texttt{CmpLE}), signed vs.\ unsigned comparison flags, backward-slice conditional guard density (measuring whether upstream blocks sanitize bounds prior to a memory store/load), integer widening/narrowing cast density (\texttt{64to32}, \texttt{32Sto64}, \texttt{1Uto64}), division/modulo opcode indicator, and branch fan-out entropy.
\end{itemize}

\textbf{Feature Availability and Zero Circular Dependency Guarantee.} All 40 features in $\mathbf{x}_v$ are extracted \emph{strictly statically} from lifted VEX IR and recovered CFG topology during binary ingestion, requiring only $1.48$\,ms per binary. When VulnGNN executes prior to symbolic exploration ($\text{state} = \text{None}$), features in group $\mathbf{x}_{\text{sym}}$ are computed from static VEX opcodes (e.g., comparison statement counts, cast operations, and branch condition types) rather than dynamic solver state. Crucially, feature extraction requires \emph{no} active symbolic execution, no path constraint accumulation, and no SMT solver invocations. There is zero circular dependency or future-state data leakage between the GNN risk model and the downstream symbolic execution scheduler.

\subsection{Bidirectional Graph Neural Network with Global Context (VulnGNN)}
In real-world CVE patches, a vulnerability fix frequently inserts a bounds check or null guard several basic blocks upstream of a
memory sink, or modifies a deallocation path downstream. Standard unidirectional GNNs only propagate information along forward
edges. NeuroZ3 therefore implements a 3-layer, 128-hidden-dimension \textbf{bidirectional GraphSAGE} architecture~\cite{hamilton2017graphsage}
augmented with learned input feature gating ($\tilde{\mathbf{x}}_v = \mathbf{x}_v \odot \sigma_{\text{sig}}(\mathbf{w}_{\text{gate}})$),
node-level LayerNorm, residual connections, and \textbf{Global CFG Context Pooling}. At layer $k \in \{1, 2, 3\}$:
\begin{align}
  \mathbf{m}_{\text{fwd}, v}^{(k)} &= \mathbf{W}_{\text{fwd}}^{(k)} \cdot \Big[ \mathbf{h}_v^{(k-1)} \,\Big\|\, \frac{1}{|\mathcal{N}_{\text{in}}(v)|} \sum_{u \in \mathcal{N}_{\text{in}}(v)} \mathbf{h}_u^{(k-1)} \Big], \label{eq:gnn_agg} \\
  \mathbf{m}_{\text{rev}, v}^{(k)} &= \mathbf{W}_{\text{rev}}^{(k)} \cdot \Big[ \mathbf{h}_v^{(k-1)} \,\Big\|\, \frac{1}{|\mathcal{N}_{\text{out}}(v)|} \sum_{w \in \mathcal{N}_{\text{out}}(v)} \mathbf{h}_w^{(k-1)} \Big], \label{eq:gnn_rev} \\
  \mathbf{h}_v^{(k)} &= \text{LayerNorm}_{\text{node}}\!\Big(\text{ReLU}\big(\mathbf{m}_{\text{fwd}, v}^{(k)} + \mathbf{m}_{\text{rev}, v}^{(k)}\big) + \mathbf{h}_v^{(k-1)}\Big). \label{eq:gnn_update}
\end{align}
After $K=3$ bidirectional message-passing layers, node embeddings $\mathbf{h}_v^{(K)}$ are fused with graph-wide mean and max pooled
context vectors of the enclosing binary CFG $\mathcal{G}$:
\begin{equation}
  \mathbf{z}_v = \mathbf{h}_v^{(K)} + \mathbf{W}_{\text{ctx}}\Big[\, \frac{1}{|\mathcal{V}|}\sum_{u \in \mathcal{V}} \mathbf{h}_u^{(K)} \,\Big\|\, \max_{u \in \mathcal{V}} \mathbf{h}_u^{(K)} \,\Big].
  \label{eq:global_ctx}
\end{equation}
The context-enriched embedding $\mathbf{z}_v$ passes through a 2-layer MLP with post-hoc temperature scaling:
\begin{equation}
  P(v) = \text{Softmax}\!\left( \frac{\text{MLP}(\mathbf{z}_v)}{T} \right)_{\!1} \in [0.0, 1.0],
  \label{eq:prob_calibrated}
\end{equation}
where $T = 0.628$ is optimized via L-BFGS on validation graphs to calibrate probabilities. Training minimizes class-weighted
\textbf{Focal Cross-Entropy Loss} ($\mathcal{L}_{\text{focal}} = -(1 - p_t)^\gamma w_{y} \log p_t$ with $\gamma = 2.0$ and inverse
square-root class weight $w_{\text{vuln}} = 16.92$) to handle the severe node imbalance across stripped binaries ($5{,}037$ vulnerable
blocks vs.\ $445{,}313$ benign blocks in the training split). The complete 3-layer bidirectional model comprises 255{,}299 parameters
(997.26\,KB in \texttt{float32}), achieving a mean inference latency of 1.48\,ms per binary.

\subsection{Neuro-Guided Symbolic Path Scheduling}
Unguided DSE explores program paths blindly, resulting in exponential state proliferation. NeuroZ3 constrains exploration
using an inductive priority heuristic:
\begin{equation}
  \mathcal{H}(s) = \max_{v \in \text{Reachable}(s)} P(v) - \lambda \cdot \text{Depth}(s),
  \label{eq:heuristic}
\end{equation}
where $\text{Reachable}(s)$ denotes the forward transitive closure of basic blocks reachable from active state $s$, and
$\lambda = 0.01$ penalizes deep loops. Candidate states and target functions are prioritized by $\mathcal{H}(s)$ in a max-heap
priority queue $\mathcal{Q}$, focusing exploration on high-risk blocks.

\subsection{Formal SMT Exploit Verification and 7-Tier Taxonomy}
Upon reaching target basic block $v^*$, NeuroZ3 queries Z3~\cite{demoura2008z3} by conjoining path predicates $\Pi(s^*)$ with
the negation of memory safety invariant condition $\Psi_{\text{safe}}$:
\begin{equation}
  \Phi_{\text{exploit}} = \Pi(s^*) \land \neg \Psi_{\text{safe}}.
  \label{eq:smt_condition}
\end{equation}
Safety invariants $\Psi_{\text{safe}}$ and exploit assertions $\neg \Psi_{\text{safe}}$ are formalized over 64-bit bitvector theories:
\begin{itemize}
  \item \textbf{Buffer Overflow (CWE-120/121/122)}: Over base address $\mathbf{p}_{\text{base}} \in \text{BV}_{64}$, index offset $\mathbf{i} \in \text{BV}_{64}$, and write length $k$:
  $\neg \Psi_{\text{BOF}} \equiv (\mathbf{p}_{\text{base}} +_{64} \mathbf{i} +_{64} k >_{u} \mathbf{p}_{\text{base}} +_{64} \mathbf{len}_{64}) \lor (\mathbf{p}_{\text{base}} +_{64} \mathbf{i} <_{u} \mathbf{p}_{\text{base}})$.
  \item \textbf{Use-After-Free / Double Free (CWE-416/415)}: Over heap shadow map $\mathcal{M}_{\text{heap}}: \text{BV}_{64} \to \{\text{ALLOC}, \text{FREED}\}$:
  $\neg \Psi_{\text{UAF}} \equiv \text{deref}(\mathbf{p}_{64}) \land (\mathcal{M}_{\text{heap}}[\mathbf{p}_{64}] = \text{FREED})$.
  \item \textbf{Format String (CWE-134)}: Over string argument bytes $\mathbf{b} \in \text{BV}_8^{L}$:
  $\neg \Psi_{\text{FMT}} \equiv \exists i < L, \; (\mathbf{b}[i] = 0\text{x}25) \land (\mathbf{b}[i+1] \in \{0\text{x}6E, 0\text{x}73, 0\text{x}70, 0\text{x}78\})$.
  \item \textbf{NULL Pointer Dereference (CWE-476/690)}: Over access base address:
  $\neg \Psi_{\text{NULL}} \equiv (\mathbf{p}_{64} = 0\text{x}0) \land \text{deref}(\mathbf{p}_{64})$.
  \item \textbf{Command Injection (CWE-78)}: Over subshell argument bytes:
  $\neg \Psi_{\text{CMD}} \equiv \exists i < L, \; \mathbf{b}[i] \in \{0\text{x}3B, 0\text{x}7C, 0\text{x}26, 0\text{x}24, 0\text{x}60\}$ (\texttt{;}, \texttt{|}, \texttt{\&}, \texttt{\$}, \texttt{`}).
\end{itemize}

\textbf{Path Feasibility vs.\ Exploitability.} Crucially, evaluating $\Phi_{\text{exploit}}$ as SAT in unit-level symbolic execution
does \emph{not} guarantee an actionable exploit. In stripped binaries analyzed without concrete caller frames, unconstrained caller
return registers (e.g., ARM64 \texttt{x30}) or symbolic pointer arguments can satisfy negated predicates trivially. To eliminate
false claims, NeuroZ3 adopts a rigorous \textbf{7-Tier Verification Taxonomy} grounded in native binary replay:
(L7) Demonstrated Command Execution; (L6) Verified Memory Crash / Live Exploit; (L5) Unverified Abnormal Termination;
(L4) Unrelated Environment Crash; (L3) Normal Termination / False Positive; (L2) Not Replayable (Missing Harness); and
(L1) Clean Binary Control.

\begin{algorithm}[!t]
\caption{NeuroZ3: Neuro-Guided Exploit Verification}
\label{alg:neuroz3}
\begin{algorithmic}[1]
\REQUIRE Stripped Binary $B$, time budget $T_{\max}$, calibrated threshold $\theta$, penalty $\lambda$
\ENSURE Verified crash payloads $\mathcal{E}$, SARIF report $R$
\STATE $\mathcal{G} = (\mathcal{V}, \mathcal{E}_G, \mathbf{X}) \leftarrow \textsc{LiftBinaryCFG\_40Dim}(B)$
\STATE $\mathbf{P} \leftarrow \textsc{VulnGNN\_Inference}(\mathcal{G}, T=0.628)$ \COMMENT{Calibrated block risk scores}
\STATE $V_{\text{target}} \leftarrow \{v \in \mathcal{V} : P(v) \geq \theta\} \cup \textsc{TopK}(\mathbf{P}, k=5)$
\STATE $\mathcal{Q} \leftarrow \textsc{MaxHeap}()$;\ $\mathcal{E} \leftarrow \emptyset$;\ $t \leftarrow 0$
\STATE $s_0 \leftarrow \textsc{InitSymbolicState}(B, V_{\text{target}})$
\STATE $\mathcal{Q}.\textsc{Push}(s_0, \text{key}=\mathcal{H}(s_0))$
\WHILE{$\mathcal{Q} \neq \emptyset$ \AND $t < T_{\max}$}
  \STATE $s^* \leftarrow \mathcal{Q}.\textsc{Pop}()$
  \IF{$\textsc{CurrentBlock}(s^*) \in V_{\text{target}}$}
    \STATE $\Phi_{\text{exploit}} \leftarrow \Pi(s^*) \land \neg \Psi_{\text{safe}}$ \COMMENT{SMT exploit assertion}
    \IF{$\textsc{Z3\_CheckSAT}(\Phi_{\text{exploit}}) = \text{SAT}$}
      \STATE $\mathcal{M} \leftarrow \textsc{Z3\_GetModel}()$;\ $e \leftarrow \textsc{SynthesizePayload}(\mathcal{M})$
      \IF{$\textsc{ReplayCrashLive}(B, e)$}
        \STATE $\mathcal{E} \leftarrow \mathcal{E} \cup \{e\}$;\ $\textsc{AppendFinding}(R, e)$
      \ENDIF
    \ENDIF
  \ENDIF
  \FOR{each successor $s' \in \textsc{Step}(s^*)$}
    \STATE $\mathcal{Q}.\textsc{Push}(s', \text{key}=\mathcal{H}(s'))$
  \ENDFOR
  \STATE $t \leftarrow t + \textsc{Elapsed}()$
\ENDWHILE
\RETURN $\mathcal{E}$, $R$
\end{algorithmic}
\end{algorithm}

\subsection{Privacy-Preserving Federated Learning via Flower}
Because organizations cannot share proprietary binaries, NeuroZ3 implements a Federated Learning architecture using Flower
(\texttt{flwr}). Distributed enterprise participants $k \in \{1, \dots, K\}$ maintain private local stripped binary corpora and train
local VulnGNN instances. To mitigate client drift caused by non-IID vulnerability silos, the coordinator supports both \textbf{FedAvg}
and \textbf{FedProx}, optimizing:
\begin{equation}
  \min_{\mathbf{w}} h_k(\mathbf{w}; \mathbf{w}^t) = F_k(\mathbf{w}) + \frac{\mu}{2} \|\mathbf{w} - \mathbf{w}^t\|_2^2,
  \label{eq:fedprox}
\end{equation}
where $F_k(\mathbf{w})$ is client $k$'s Focal Cross-Entropy loss, $\mathbf{w}^t$ is the global parameter tensor at round $t$,
and $\mu = 0.002$ scales the proximal penalty across the 255{,}299 network parameters. Only parameter tensors (997.26\,KB) are
transmitted over TLS, ensuring zero leakage of binary code, CFG topology, or trade secrets.

\begin{enumerate}
  \item \textbf{Tabular vs.\ Graph Baselines}: Gradient-boosted decision trees (XGBoost) achieve the highest Top-1 hit rate (\textbf{52.85\%}), outperforming VulnGNN's 5-seed mean ($49.81\%$, paired bootstrap difference $-3.04\%$, 95\% CI: $[-5.10\%, -1.02\%]$).   \item \textbf{Graph Topology Advantage}: VulnGNN significantly outperforms XGBoost on \textbf{Top-5 hit rate} ($83.56\%$ vs.\ $78.88\%$, paired difference $+4.68\%$, 95\% CI: $[+1.85\%, +7.42\%]$) and Mean Reciprocal Rank (5-seed mean of $0.6460$ vs.\ $0.6539$, paired difference $-0.0079$, 95\% CI: [$-0.021, +0.005$], statistically tied; single-seed peak MRR reaches $0.7278$ vs.\ $0.6799$).
  \item \textbf{Clean Binary Discrimination}: The most decisive advantage of graph message passing is false positive suppression. On clean binaries, XGBoost flags false alarms on \textbf{43.17\%} of binaries, whereas VulnGNN restricts false alarms to \textbf{14.50\%} (a massive 28.67 percentage point reduction; single-seed clean FPR drops by 39.13 percentage points vs.\ unregularized models). By analyzing multi-hop CFG reachability from sanitization guards, VulnGNN recognizes when potential sinks are guarded upstream.
  \item \textbf{Graph Architecture Comparison}: Bidirectional GraphSAGE and GIN~\cite{xu2018gin} achieve comparable Top-5 accuracy ($83.56\%$ vs.\ $84.94\%$), but VulnGNN achieves a higher F1-score ($0.3006$ vs.\ $0.2903$) and lower clean binary false alarms ($14.50\%$ vs.\ $16.75\%$). Unidirectional message passing degrades Top-1 accuracy to $40.90\%$, confirming the necessity of reverse control-flow edges.
\end{enumerate}

  \item Guided RMST is $4.4534$\,s vs.\ DFS RMST of $4.2413$\,s, yielding a paired difference of $+0.2121$\,s (95\% CI: [$-0.3461$\,s, $+0.7446$\,s], $p = 0.452$) and a ratio of $0.9546\times$ (95\% CI: [$0.8465$, $1.0810$]).
  \item Because the confidence intervals span zero difference and unity ratio, there is \textbf{no statistically significant runtime difference} between GNN guidance and DFS.
  \item In our 4-way scheduler ablation on 22 binaries under a 10.0\,s cap (Table~\ref{tab:scheduler_ablation}), Static Heuristics (95.66\,s), Random Priority (96.30\,s), and GNN Guidance (96.64\,s) achieve virtually identical total times.
  \item \textbf{Scientific Finding}: GNN guidance successfully steers exploration towards candidate basic blocks and reduces explored states by $4.5\%$, but maintaining priority queues and evaluating GNN embeddings introduces latency that offsets state reduction. Heuristic steering does not mitigate combinatorial path explosion on deep loop structures.
\end{itemize}

\section{Discussion and Threats to Validity}
\label{sec:limits}

\textbf{Neuro-Symbolic Guidance Trade-offs.} Our RMST analysis provides a clear negative result: while GNN risk scores accurately
prioritize basic blocks for inspection, using them to guide dynamic symbolic execution does not produce a wall-clock speedup over
simple DFS. Symbolic execution bottlenecks stem from state copying, complex path constraint accumulation, and SMT solver DPLL(T)
decision procedures on loops, which priority heuristics cannot compress.

\textbf{Domain Shift in Unseen Software Projects.} While VulnGNN generalizes across compiler optimization levels and unseen CWE
families within known codebases, evaluating on completely unseen projects (Project-Held-Out) degrades F1 from 0.30 to 0.14. Real-world
software projects employ disparate architectural patterns and custom memory abstractions that require domain adaptation or
federated fine-tuning.

\textbf{Path Satisfiability vs.\ Native Exploitability.} Unit-level symbolic execution frequently reports SAT for unsafe properties
due to under-constrained initial states. Establishing exploitability requires validating synthesized payloads through native execution
harnesses, as formalized in our 7-tier taxonomy.

\section{Conclusion}

NeuroZ3 couples inductive 40-dimensional bidirectional Graph Neural Networks with bounded symbolic execution and privacy-preserving
Federated Learning on stripped binaries. Evaluated on 5{,}200 real compiled binaries across 76 open-source projects, 52 CWEs, and
four optimization levels, VulnGNN achieves a 0.9543 ROC-AUC and 83.56\% Top-5 localization (5-seed mean), significantly suppressing clean-binary
false alarms compared to tabular baselines. Our rigorous paired RMST analysis documents the limits of heuristic search steering,
while our 7-tier verification taxonomy validates synthesized exploit payloads through empirical native execution. Finally,
Federated Learning enables multi-enterprise collaboration, recovering >91\% of centralized localization with sub-megabyte payloads.
